# PRD：心理测评站（Survey Platform）

> 版本 0.1 · 2026-10-27 · 状态：MVP 开发中

## 1. 一句话定位

一个「声明式问卷引擎 + 多量表合集」的静态测评网站：开发者以「量表包」形式上传任意心理/性格测评，访客在浏览器内完成作答并立即得到评分结果。

## 2. 背景与目标

- 用户（开发者）希望搭建一个类似 MBTI / 心理健康测评的问卷填写网站。
- 无自有服务器，采用零成本托管（Cloudflare Pages），后续视需要升级。
- 访客数据暂不上云，结果仅保存在客户端，但架构需预留统计接口。

## 3. 用户角色

| 角色 | 说明 |
|---|---|
| 访客 | 浏览量表列表、作答、查看结果与本机历史 |
| 开发者 | 通过在仓库中新增「量表包」来上架/更新测评（非运行时上传） |

## 4. 功能需求（MVP）

- F1 量表首页：列出全部可用量表（名称、简介、预计用时）。
- F2 答题页：逐题作答，支持两类题型——
  - `single`：单选/强迫选择题，每个选项携带显式计分；
  - `scale`：李克特量表题（1..N 刻度，支持反向计分、维度权重）。
- F3 作答进度自动保存在本地（刷新不丢），提交后清除草稿。
- F4 计分：完全由量表包的 `scoring.json` 声明驱动，支持两种策略——
  - `letter-pairs`：维度配对取高者，拼接为结果 id（MBTI 模式）；
  - `thresholds`：总分区间判级（SDS 模式）。
- F5 结果页：结果标题/描述/建议，letter-pairs 附维度倾向条形图，thresholds 附总分。
- F6 本机历史：结果保存于 localStorage，可回看（当前通过结果页回退逻辑体现）。

## 5. 非功能需求

- N1 纯静态、零后端；所有计分在浏览器完成。
- N2 隐私：作答与结果默认不上传（预留 `AnalyticsService` 接口）。
- N3 部署：Cloudflare Pages，push 即自动部署；SPA 需 `_redirects` 兜底路由。
- N4 可扩展：新增量表 = 新增一个文件夹 + 4 个 JSON，不改引擎代码。

## 6. 非目标（暂不做）

- 用户账号体系、云端答卷统计、防作弊
- 用户自助上传题库
- 结果分享海报生成（后续版本）
- 多语言

## 7. 首批量表

| 量表 | 题数 | 计分策略 |
|---|---|---|
| MBTI 人格类型测评（93 题） | 93 | letter-pairs |
| 抑郁自评量表 SDS | 20 | thresholds |

## 8. 成功标准

- 访客可在手机/桌面浏览器顺畅完成一次测评并看到正确结果。
- 开发者新增一个量表包即可上架新测评，无需修改引擎。
- Lighthouse 基础分良好，首屏加载 < 2s（Pages CDN）。
