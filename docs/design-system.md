# 设计规范（Design System）

> 本文档是全站视觉与排版的唯一规范。任何页面/组件的新增或修改都必须遵循本文档；若需要偏离或扩展规范，先更新本文档再动代码。
> 事实来源：[style.css](../src/style.css)（全局变量与基础组件）。

## 1. 设计原则

1. **内容优先**：测评工具的本质是「读题 → 作答 → 看结果」，视觉服务于可读性与专注度，不做装饰性堆砌
2. **少即是多**：能不加的元素不加；信息层级用字号/颜色区分，而非新增色块
3. **双主题一等公民**：任何新样式必须同时在浅色与深色模式下检查（用 CSS 变量，禁止硬编码颜色——分享图 canvas 除外）
4. **移动端优先**：以 375px 宽为基准设计，桌面端只做宽度放大

## 2. 色彩系统（CSS 变量）

| 变量 | 用途 | 浅色 | 深色 |
|---|---|---|---|
| `--bg` | 页面背景 | `#f6f7f9` | `#12141a` |
| `--card` | 卡片/面板背景 | `#ffffff` | `#1c1f28` |
| `--text` | 正文/标题 | `#1f2430` | `#e8eaf0` |
| `--muted` | 次要文字、说明 | `#7a8194` | `#9aa2b5` |
| `--accent` | 品牌主色：按钮、链接、强调 | `#4f6ef7` | `#7b93ff` |
| `--accent-weak` | 主色的弱背景（选中态、徽章底） | `#eef1fe` | `#262c44` |
| `--line` | 边框、分隔线、进度条轨道 | `#e5e8ef` | `#353b4b` |
| `--shadow` | 浮层阴影 | `rgba(0,0,0,.08)` | `rgba(0,0,0,.4)` |
| `--danger` | 危险/警示文字（答题卡缺答、清空历史） | `#d9534f` | `#e57373` |

**使用规则**：

- 正文中禁止使用 `--accent` 之外的彩色；状态提示（如错误）如需引入新色，先在此表登记
- 文字对比度：`--text` 用于主内容，`--muted` 只用于辅助信息（说明、meta、免责声明），禁止用 `--muted` 写需要用户必读的内容

## 3. 字体与字号

- 字体栈（`body` 上声明，组件不重复声明）：中文优先本地栈 `MiSans → HarmonyOS Sans SC → PingFang SC → Microsoft YaHei UI/微软雅黑 → Noto Sans SC`，数字/字母由排在前面的 `Segoe UI` 混排：

  ```css
  font-family: 'Segoe UI', 'MiSans', 'HarmonyOS Sans SC', 'PingFang SC',
    'Microsoft YaHei UI', 'Microsoft YaHei', 'Noto Sans SC', system-ui, sans-serif;
  ```

- 展示字体：`LXGW WenKai Screen`（霞鹜文楷屏幕版，CDN 引入，见 index.html），**只用于展示性文字**——顶栏站名、首页 hero 站名、结果代号等，通过全局 `.font-display` 类挂载；正文/按钮/表单一律用默认字体栈
- 字号档位（页面内使用，禁止其他中间值）：

| 档位 | 用途 |
|---|---|
| 40px+ / 32px(mobile) | 结果代号大字（result-id） |
| 22px | 页面主标题（h1） |
| 18px | 卡片标题（h2） |
| 15px | 正文、按钮 |
| 14px | 次要说明、选项、导航 |
| 13px | 面板小标题、meta |
| 12px | 免责声明、页脚 |

- 行高：正文 `1.6~1.8`；标题单行
- 强调用 `font-weight: 600~800`，不靠加颜色

## 4. 间距与布局

- **4px 基数**：所有间距取 4 的倍数（4/8/12/16/20/24/32/48）
- 页面主容器（`--main`）：`max-width: 760px` 居中；内边距 `24px 16px 48px`（移动端 `16px 12px 40px`）
- 卡片内边距：`20px`（移动端 `16px`）
- 组件间垂直间距：`16px`（紧凑场景 `8px`，分组间 `24px`）
- 卡片列表间距：`16px`

## 5. 圆角与阴影

| 元素 | 圆角 |
|---|---|
| 卡片 / 设置面板 / 结果卡 | `12px` |
| 按钮 / 输入框 / 徽章 | `8px` / `6px` |
| 进度条、开关、维度条 | 全圆角（高度一半） |
| 分享图外卡 | `24px` |

- 阴影只用于**浮层**（设置面板等 `position: absolute` 元素）：`0 8px 24px var(--shadow)`；页面内卡片用边框 `1px solid var(--line)` 区分，不加阴影
- **唯一例外**：首页量表卡片 `.survey-card` hover 态允许上浮 `translateY(-2px)` + `0 8px 20px var(--shadow)`（transition 0.2s），深浅色经 `--shadow` 变量自适应

## 6. 基础组件规范

### 按钮 `.btn`

- 主按钮：`--accent` 底 + 白字，`padding: 10px 22px`，hover 时 `opacity: .88`
- 次按钮（`.btn.ghost`）：`--card` 底 + `--text` 字 + `1px solid var(--line)` 边框
- 禁用态：`--line` 底 + `--muted` 字 + `not-allowed`
- 一个操作区最多 **1 个主按钮**，其余用 ghost

### 卡片 `.card`

- `--card` 底 + 1px 边框 + `12px` 圆角 + `20px` 内边距
- 卡片头部（标题行）：标题左、徽章/meta 右，`justify-content: space-between`

### 表单控件

- 输入框：`1px solid var(--line)`、`6px` 圆角、`--card` 底；禁用 `opacity: .5`
- 开关（iOS 风格）：`36×20px` 轨道，off 为 `--line`，on 为 `--accent`

### 动效

- 只用 `transition`，时长 `0.15s`（微交互）/ `0.2s`（主题切换）
- 自动下一题延迟默认由用户设置控制，动效不得阻塞作答

## 7. 图标与图形

- 图标统一用 **emoji**（⚙ ☀️ 🌙 以及分类 Tab 的 🧩🧠🎉），不引入图标库
- 分类图标底座 `.cat-chip`：34×34px、圆角 9px、底色为分类色 + 15% 透明度（见 §2.1），用于量表卡片左上角与详情页
- 维度条形图：轨道 `--line` 高 `10px` 全圆角，填充 `--accent`；领先一侧文字 `--accent` 加粗
- **ScoreGauge 分数表盘**（`src/components/ScoreGauge.vue`）：仅 thresholds 策略量表显示，插入结果卡「代号/标题」与解读文字之间。水平色带（绿→黄→橙→红，档数适配）+ 等比刻度线 + 带数值指针气泡；桌面端色带下方标注每档名称，≤480px 隐藏档名行、改显「当前档」行。纯 CSS 实现，不引第三方图表库
- 分享图（canvas）独立规范：固定浅色（渐变 `#5b6ff0 → #8a5cf6`）、2x 导出、底部标注日期 + 域名 + 免责声明

## 8. 页面骨架约定

```
┌─ topbar ─────────────────────────────┐  左：站点名；右：历史 · ⚙ · ☀️/🌙
├─ main (max-760) ─────────────────────┤
│   页面 h1 (22px)                     │
│   内容卡片（.card 列表，间距 16px） │
├─ footer ─────────────────────────────┤  © 版权 · 免责声明 · GitHub 链接（12px, --muted）
└──────────────────────────────────────┘
```

- 页面级操作（如「返回首页」「再测一次」）集中在内容末尾的 `.actions` 区，不放进页脚
- 空状态必须给出下一步引导按钮（如历史页空态 → 「去做测评」）

## 9. 变更流程

1. 需要新颜色/字号/间距档位 → 先在本文档对应表格登记，再写代码
2. 视觉改动完成后：浅色 + 深色 + 375px 宽度三态自检
3. 本文档与代码不一致时，以尽快修正任一方为原则，不允许长期分叉
